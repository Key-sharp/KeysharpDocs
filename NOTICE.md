# Provenance and independence

KeysharpDocs is documentation for Keysharp, an independent project.

This repository was initially derived from the `alpha` branch of
[AutoHotkeyDocs](https://github.com/AutoHotkey/AutoHotkeyDocs), including its
Git history, and is maintained as a visibly separate work for Keysharp.
The adaptation is made with permission from the AutoHotkey project.

Keysharp is not affiliated with, sponsored by, or endorsed by the AutoHotkey
project. AutoHotkey branding is not used to identify Keysharp or KeysharpDocs.
References to AutoHotkey remain where they are necessary to describe language
compatibility, preserve attribution, cite upstream material, or document
historical behavior.

Original copyright and attribution notices remain in inherited pages and the
repository history. They identify work by Steve Gray, Chris Mallett, the
AutoIt Team, and other contributors; additional credits are listed in
`docs/misc/Acknowledgements.htm`.

Keysharp-specific documentation and modifications are contributed through this
repository. See `docs/license.htm` for the distinction between:

- the Keysharp software license;
- the permission and provenance of this documentation derivative; and
- the archived AutoHotkey software license text inherited with the source
  documentation.

Nothing in this notice implies organizational affiliation or endorsement.
