Compatibility Differences

This page indexes intentional extensions, implementation differences and unavailable inherited behavior relative to the AutoHotkey v2.1-alpha.30 compatibility target. Each link leads to the canonical contract.

Note: The absence of an item here does not prove that inherited behavior has been verified on every platform. See Platform Support and platform remarks on the affected page.

Runtime and Language

  • Scripts compile to .NET assemblies instead of being interpreted.
  • Object lifetime and finalization follow the .NET garbage collector.
  • Increment/decrement, concatenation assignment, numeric literals, unset values and dynamic dereferencing have documented implementation differences.
  • Reference parameters accept additional target forms, while the reference operator returns a VarRef rather than a raw address.
  • Conditional-compilation directives and Keysharp build directives extend the language.
  • The KS module contains Keysharp-specific APIs.

Memory and Interop

  • StringBuffer is the preferred writable string-memory type for native calls.
  • StrPtr, ObjPtr, reference counting, CallbackCreate and DllCall reflect the managed runtime.
  • Clr provides experimental direct .NET interop.

GUI and Desktop Integration

  • Gui includes container-relative positioning, GroupBox containers, automatic scrolling, macOS application menus and visibility access.
  • GUI controls document toolkit-specific additions and unavailable Win32 behavior.
  • GuiControl, ListView, TreeView and Menu have additional methods and properties.
  • WinEvent, Overlay and Image add cross-platform desktop facilities.
  • Platform Support describes X11, Wayland, macOS permissions and foreign-window automation.

Additional APIs

  • Keysharp built-in variables
  • String and Base64 functions
  • Cryptographic and checksum functions
  • File path functions
  • C# regular-expression functions
  • FormatCs
  • RequestCapabilities
  • Clipboard helper functions
  • RunScript and ProcessInfo
  • RealThread and LockRun
  • Mail
  • Collect

Unavailable or Reduced Inherited Behavior

The affected reference pages document the exact boundary. Notable areas include:

  • ListLines;
  • FormatTime flags and PixelGetColor mode;
  • DirSelect and MsgBox modality;
  • OnMessage dispatch, Thread line awareness and Download options; and
  • toolkit-specific control behavior in GUI Control Types and GUI Events.
