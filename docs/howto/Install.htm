How to Install Keysharp

Download the package for your operating system from the Keysharp releases page. Keysharp targets .NET 10; check the selected release notes for its runtime and platform requirements.

Development status: Keysharp is under active development. Windows has the broadest feature coverage. Linux and macOS support are improving, but operating-system-specific functions may be unavailable. Check the capability matrix before relying on a feature.

Windows

  1. Download the Windows installer from the releases page.
  2. Run the installer and follow its prompts.
  3. Create a plain-text script named hello.ks.
  4. Run it with Keysharp.exe hello.ks, or use the file association installed with Keysharp.

Keysharp also includes Keyview, its script viewer and editor utility.

Linux

  1. Download and extract the Linux archive for your architecture.
  2. For a system-wide installation, run sudo bash ./install.sh. Run the same command without sudo for a user-local installation.
  3. Start a script with keysharp hello.ks.

Some editor extensions expect an executable named AutoHotkey.exe. The Linux package can install a compatibility shim for this purpose; the name does not indicate an AutoHotkey installation or affiliation.

macOS

Keysharp supports current Intel and Apple silicon macOS packages. Download the matching osx-x64 or osx-arm64 archive and follow the release instructions. If macOS quarantines the downloaded executable or Keyview application, use the quarantine-removal command documented in the release package only after verifying that the archive came from the official Keysharp release page.

Keyboard, accessibility, and automation features can require permissions in System Settings → Privacy & Security.

Verify the Installation

Create hello.ks with this content:

MsgBox "Hello from Keysharp!"

Then run:

Keysharp.exe hello.ks

On systems where the command is installed in lowercase, use:

keysharp hello.ks

Problems?

Search or report installation problems in the Keysharp issue tracker. Include the Keysharp version, operating system, architecture, install method, and the complete error message.
