Crypt

class Crypt extends Object

Hashes values and files, encrypts and decrypts with AES, derives keys from passwords, and returns cryptographically secure random values. Every method is called on the class itself; a Crypt object is never constructed.

The class is exported by the KS module:

#Import "Ks" { Crypt }

Hash

Returns the digest of a value, using any supported algorithm.

Digest := Crypt.Hash(Value , Algorithm := "SHA256", Encoding := "UTF-8")

Parameters

Value

Type: String, Buffer, Array or File

The data to hash. See Input Values and Text Encoding.

Algorithm

Type: String

If omitted, it defaults to SHA256. Otherwise specify MD5, SHA1, SHA256, SHA384, SHA512 or CRC32. The name is not case-sensitive, and may be written with the hyphen other tools print, so SHA-256 is accepted as well as SHA256.

Encoding

Type: String

The encoding a String Value is converted to before hashing, named as for A_FileEncoding. If omitted, it defaults to UTF-8. It has no effect on any other type of value.

Return Value

Type: String

The digest as uppercase hexadecimal. See Digest Format.

Error Handling

A ValueError is thrown if Algorithm is not one of the names listed above, or if Value is a File which is not open for reading. A TypeError is thrown if Value is a type which holds no bytes, such as a number.

HashFile

Returns the digest of a file, read as a stream.

Digest := Crypt.HashFile(Path , Algorithm := "SHA256")

Parameters

Path

Type: String

The name of the file, which is assumed to be in A_WorkingDir if an absolute path is not specified.

Algorithm

Type: String

As for Hash.

Return Value

Type: String

The digest as uppercase hexadecimal.

Remarks

The file is read a block at a time and is never held in memory as a whole, so the size of the file does not matter. Hashing the same bytes read by FileRead with the RAW option produces the same digest, at the cost of loading the entire file first.

Error Handling

A ValueError is thrown if Path is empty or Algorithm is not recognized. An OSError is thrown if the file cannot be opened or read, and A_LastError is set to the operating system's error code.

MD5, SHA1, SHA256, SHA384, SHA512

Return the digest of a value with one named algorithm.

Digest := Crypt.MD5(Value , Encoding := "UTF-8")
Digest := Crypt.SHA1(Value , Encoding := "UTF-8")
Digest := Crypt.SHA256(Value , Encoding := "UTF-8")
Digest := Crypt.SHA384(Value , Encoding := "UTF-8")
Digest := Crypt.SHA512(Value , Encoding := "UTF-8")

Each is Hash with the algorithm fixed, and accepts the same values. The digests are 32, 40, 64, 96 and 128 characters long respectively.

Security warning: MD5 and SHA-1 are unsuitable for collision-resistant security uses. Use SHA-256 or stronger unless compatibility requires an older digest.

CRC32

Returns the CRC32 checksum of a value as an integer.

Checksum := Crypt.CRC32(Value , Encoding := "UTF-8")

CRC32 detects accidental corruption; it is not a cryptographic integrity check.

Crypt.Hash(Value, "CRC32") computes the same checksum but returns it as hexadecimal, which is also how HashFile reports it.

Encrypt / Decrypt

Encrypt encrypts data with a symmetric cipher; Decrypt reverses it.

Data := Crypt.Encrypt(Value, Key , Algorithm := "AES", Mode := "CBC", IV, Encoding := "UTF-8")
Data := Crypt.Decrypt(Value, Key , Algorithm := "AES", Mode := "CBC", IV, Encoding := "UTF-8")

Both return a Buffer. Algorithm is AES, which is the only cipher so far; it is a parameter rather than part of the method name, so a cipher added later is a value this accepts instead of a new method. Mode is the chaining mode: CBC (the default), ECB, which encrypts each block independently and so reveals where the plaintext repeats, or CFB — which is CFB8, the feedback size .NET and Windows CNG both default to, and not the CFB128 that OpenSSL's plain -aes-256-cfb means. Decrypting requires the same algorithm, mode, key and encoding the data was encrypted under; a wrong key, a truncated input or a mismatched mode throws a ValueError.

GCM is the fourth mode and the one to prefer: it authenticates as well as encrypts, so a message altered after the fact is detected when it is decrypted and raises a ValueError, where a chaining mode decrypts it to rubbish without complaint. Its nonce is 12 bytes rather than the 16 a chaining mode's vector takes, and its 16-byte authentication tag is appended to the result, so an encrypted message is 28 bytes longer than its plaintext. A nonce must never be reused with one key, which is what the default of drawing a fresh one per call ensures.

A String Value or Key is converted using Encoding, so reading decrypted text back requires StrGet with the same one.

The initialization vector

AES encrypts in 16-byte blocks, and in CBC mode each block is combined with the ciphertext of the one before it. The first block has no predecessor, so it is combined with a 16-byte value supplied separately: the initialization vector. The vector is not a secret and normally travels with the ciphertext, but it must differ from message to message — a fixed one makes encryption deterministic, which lets anyone holding the output see which encrypted values are equal without decrypting any of them.

With IV omitted, each call draws a random vector, uses it, and writes it in front of the result, where Decrypt reads it back. Encrypting the same text twice therefore returns different data, and the result is 16 bytes longer than the ciphertext alone. This is the recommended form, and it asks nothing of the caller.

Supply IV — 16 bytes for a chaining mode, 12 for GCM, as RandomBytes returns them — only to match a format defined elsewhere. It is then used exactly as given and is not written to the result, so Decrypt must be handed the same vector back. A vector of the wrong length, or any vector at all with ECB, which uses none, throws a ValueError. A String vector is converted with Encoding, which is therefore what decides how many bytes it comes to.

Security warning: the key is used as it stands, padded to the algorithm's key size rather than stretched by a key-derivation function, so a passphrase is only as strong as its own entropy. Derive a key with PBKDF2 rather than passing a passphrase straight to Key.

Security warning: under a chaining mode — CBC, ECB or CFB — the result carries no authentication tag, so a ciphertext altered after the fact decrypts to rubbish instead of being detected. Use GCM for anything that crosses a boundary where someone could change it.

PBKDF2

Derives key material from a password.

Key := Crypt.PBKDF2(Password, Salt , Iterations := 600000, Length := 32, Algorithm := "SHA256", Encoding := "UTF-8")

Returns Length bytes as a Buffer. This is what makes a passphrase usable as an encryption key: Encrypt takes the key exactly as it is given, zero-padded to the cipher's key size, so handing it "hunter2" directly gives a key only as strong as that word. Deriving one instead makes each guess an attacker tries cost Iterations hashes.

Salt need not be secret, but must differ per password — otherwise two people who choose the same password derive the same key — and must be stored alongside whatever the key protects, since the same salt is needed to derive the key again. RandomBytes produces one.

Algorithm is SHA1, SHA256 (the default), SHA384 or SHA512. MD5 is not offered: .NET declines to iterate it for derivation on every platform. A ValueError is thrown for any other name, for an iteration count below 1, or for a non-positive length.

The default of 600000 iterations is the figure OWASP gives for PBKDF2-HMAC-SHA256. Raising it raises the cost of an attacker's guesses and of the script's own derivation equally; lower it only to match a format defined elsewhere.

RandomBytes

Returns cryptographically secure random bytes.

Data := Crypt.RandomBytes(Count)

Returns Count bytes as a Buffer, drawn from the same generator as SecureRandom. This is what supplies an initialization vector, a salt, or key material — anywhere bytes rather than a number are needed.

SecureRandom

Returns a cryptographically secure random number.

Value := Crypt.SecureRandom(Min, Max)

If both bounds are integers, the result is an integer; if either is floating-point, the result uses floating-point bounds. The range includes Max, as Random's does. Omit both to use the implementation's full default numeric range.

For non-security uses where speed is preferred, use Random.

Input Values and Text Encoding

A String is converted to bytes with Encoding, which defaults to UTF-8. That is what other tools mean by the hash of a text, so Crypt.SHA256("abc") is the SHA-256 checksum that sha256sum, Get-FileHash and a published test vector all report for those three bytes. Name another encoding to hash a different byte sequence, such as the UTF-16 one a Windows API works with; a name which cannot be resolved throws a ValueError rather than falling back to something else, since the digest would otherwise be taken over the wrong bytes.

A Buffer or an Array of byte values is hashed exactly as it stands, so no encoding applies to it.

An open File passed to any of the hashing methods has its whole content read as a stream, from the beginning of the file, and is left at the position it was on. Pending writes are flushed first. A stream which cannot seek is read from its current position instead, and a File which is closed or was opened write-only throws a ValueError. Encrypt and Decrypt do not accept a File.

Digest Format

A digest is returned as uppercase hexadecimal with no separators. Compare digests case-insensitively — with = rather than ==, or after StrLower — because the tool a published checksum came from commonly prints it in lowercase.

Examples

Hashes text, and matches what any other tool reports for it.

#Import "Ks" { Crypt }

MsgBox Crypt.SHA256("abc")   ; BA7816BF8F01CFEA414140DE5DAE2223B00361A396177A9CB410FF61F20015AD
MsgBox Crypt.MD5("abc")      ; 900150983CD24FB0D6963F7D28E17F72

Verifies a download against a published checksum, comparing case-insensitively.

#Import "Ks" { Crypt }

Expected := "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"

if (Crypt.HashFile(A_ScriptDir "\download.zip") = Expected)
    MsgBox "Checksum matches."
else
    MsgBox "Checksum does NOT match."

Chooses the algorithm at run time, from the name a checksum file used.

#Import "Ks" { Crypt }

Algorithm := "SHA-512"
MsgBox Crypt.Hash("abc", Algorithm)

Encrypts text and reads it back.

#Import "Ks" { Crypt }

Secret := Crypt.Encrypt("hello", "my key")
Plain := Crypt.Decrypt(Secret, "my key")

MsgBox StrGet(Plain, Plain.Size, "UTF-8")   ; hello

; The same text encrypts differently every time, because each call draws its own vector.
MsgBox Crypt.Encrypt("hello", "my key").Size   ; 32: a 16-byte vector plus one 16-byte block
