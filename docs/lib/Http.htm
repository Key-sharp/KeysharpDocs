Http

class Http extends Object

Sends HTTP requests. The static shortcuts share one stateless client and are enough for a single call; a session — Http(Options) — carries default headers, credentials and a cookie jar across its own requests.

The class is exported by the KS module:

#Import "Ks" { Http }

It works on every platform. A ported script using ComObject("WinHttp.WinHttpRequest.5.1") runs on Windows only, because ComObject reaches D-Bus on Linux and Apple Events on macOS.

Static Methods

Res := Http.Get(Url , Options)
Res := Http.Post(Url , Body, Options)
Res := Http.Request(Method, Url , Body, Options)

Task := Http.GetAsync(Url , Options)
Task := Http.PostAsync(Url , Body, Options)
Task := Http.RequestAsync(Method, Url , Body, Options)

Method is any HTTP method, uppercased before it is sent. PUT, PATCH, DELETE and HEAD have no shortcut of their own and are spelled through Request.

Body is positional sugar for the Body option, on Request as well as Post.

The synchronous forms return an Http.Response. They block the calling pseudo-thread while pumping everything else, exactly as Sleep and Await do, so timers, hotkeys and the GUI stay alive; like them, they are an interruption point.

The Async forms return a Task carrying that response, so a request composes with Await, Then, Task.WhenAll and Task.WhenAny. Completion needs no callback option of its own.

These share one client which holds no cookies, so two unrelated libraries in one script that call the same host cannot see each other's state. A script that wants shared state asks for a session.

Http()

Creates a session: its own connection pool, cookie jar and default options.

Session := Http(Options)

Parameters

Options

Type: Map or Object

Any of the request options, applied as defaults to every request made through this session, plus the session options.

Session Properties

Headers

Type: Map

The headers sent with every request through this session, as a live case-insensitive Map that can be read and modified. A request's own Headers merge over these key by key. The Map is read at the moment a request is sent, so changing it does not affect a request already in flight.

Timeout

Type: Number

Seconds to wait, default 30. -1 waits indefinitely. See the Timeout option for exactly what it bounds.

BaseUrl

Type: String

Prefixed to a request URL which is not already absolute, so a session's calls name only their path. An absolute URL ignores it.

Session Methods

Res := Session.Get(Url , Options)
Res := Session.Post(Url , Body, Options)
Res := Session.Request(Method, Url , Body, Options)
Task := Session.GetAsync(Url , Options)
Task := Session.PostAsync(Url , Body, Options)
Task := Session.RequestAsync(Method, Url , Body, Options)
Session.Close()
Client := Session.ToClr()

The six request methods behave as the static ones, with the session's headers, cookies, credentials, base URL and timeout applied. ToClr returns the underlying HttpClient as an ordinary Clr object, for settings this class does not surface.

Close releases the session's connections, and a session that has been closed refuses further requests. A session left to the garbage collector releases them anyway, so this is for a script that opens many sessions and wants their sockets back promptly.

Request Options

Options are given as a Map or an object, with PascalCase keys. An unrecognized key throws a ValueError rather than being ignored, so a typo is reported where it is written instead of silently doing nothing.

These may be given per request or as session defaults. A request's own value wins; Headers merges key by key, and a request value of "" removes a header for that request only.

Headers

Type: Map

Header names to values, compared case-insensitively as HTTP compares them. Content-Type is applied to the body, and a request with no body ignores every Content-* name because there is nothing for it to describe. Every other name is sent as given, including one .NET's own header parser would refuse.

Unless it is overridden, a request carries User-Agent: Keysharp/<version>, which several major APIs require: they answer a request with no user agent at all with 403. Setting it to "" removes it, as it removes any other header.

Body

Type: String or Buffer

The request body. A string is sent as UTF-8 text/plain, a Buffer as application/octet-stream; an explicit Content-Type header replaces either.

Body and Json are one slot, so a request naming either one replaces both of the session's defaults rather than colliding with the other.

Json

Type: Any

A value encoded with Json.Encode and sent as application/json. Giving both Body and Json throws a ValueError, since each one is the body.

Timeout

Type: Number

A positive number of seconds, default 30, or -1 to wait indefinitely. Anything else throws a ValueError rather than being coerced.

It bounds the wait for the response headers and then each further piece of the body. It is an idle timeout rather than a total one, so a slow large download is not cut off part-way through while a connection that has stopped answering still is.

OnData

Type: Func

See OnData.

Session Options

These configure the connection, which .NET freezes once a request has been sent. They therefore belong to Http(Options); giving one per request throws a ValueError.

BaseUrl

Type: String

The initial value of BaseUrl.

Auth

Type: Array or String

[User, Password], or the string "Default" for the logged-in user's credentials.

These are credentials, not a scheme: the server's challenge selects Basic, Digest, NTLM, Negotiate or Kerberos, which is also the only way to reach the last two. A server that answers with something other than a 401 challenge is never asked, so preemptive Basic is a header instead: Map("Authorization", "Basic " Base64.Encode(User ":" Password)). A bearer token or an API key is likewise an ordinary header.

Proxy

Type: String

A proxy URL, with credentials in the usual http://user:pass@host:port userinfo form. "" forces a direct connection. Omitting it uses the system proxy.

IgnoreCertificateErrors

Type: Boolean

Accepts any server certificate, for a self-signed host on a private network. It disables the check that a connection is going where it claims, so it should name a specific host's session rather than be switched on globally.

Handler

Type: Clr

An HttpMessageHandler built through Clr, used exactly as given; the other session options are then not applied. Client certificates, TLS version pinning, a custom validation callback, cookie policy, connection limits and HTTP/2 settings are all reachable this way rather than through options of their own.

OnData

Continue := OnData(Chunk, Received, Total)

Receives the body as it arrives, so a large response never has to become a large script value.

Chunk

Type: Buffer

The bytes received since the previous call.

Received

Type: Integer

The total number of bytes received so far, including this chunk.

Total

Type: Integer

The body length the server declared, or -1 when it declared none.

Bytes accumulate for about 100 ms before each call, which bounds the callback rate on a fast transfer without ever dropping one. Because the body went to the callback, Body and Text on the response are then empty.

The callback runs as a pseudo-thread on the script thread that asked for the request, so A_ variables, GUI access and error reporting all behave normally. The transfer waits for it to return, which is what keeps memory bounded, but the wait occupies no thread of its own, and Timeout is not charged for the callback's own runtime — a slow callback is never reported as a dead server. Uninterruptibility is skipped, as it is for a message AutoHotkey sends rather than posts, so a Critical section cannot cost the transfer a chunk.

The callback may declare fewer than three parameters, as any callback may. An error raised inside it fails the request.

Stopping a transfer

Returning a non-zero Integer stops the transfer, in the same way a non-zero return from an OnExit callback prevents an exit. Anything else continues: 0, an empty string, a string, an object, or no return value at all.

The task is then canceled. The Async form leaves a Task whose Status is "Canceled"; the synchronous form throws what Await throws for canceled work.

Take care with a fat arrow, whose value is its last expression. This stops after the first chunk, because RawWrite returns the number of bytes written:

Http.Get(Url, {OnData: (Chunk, *) => File.RawWrite(Chunk)})       ; wrong
Http.Get(Url, {OnData: (Chunk, *) => (File.RawWrite(Chunk), 0)})  ; right

Stopping from outside the callback — a hotkey, a Cancel button — is a flag the next call reads. A transfer can only stop between chunks in any case, and a connection that has stopped answering is what Timeout is for.

Http.Response

class Http.Response extends Object

What a server answered. A response is never constructed by a script.

Status

Type: Integer

The status code, such as 200 or 404.

StatusText

Type: String

The reason phrase, such as "OK".

IsSuccess

Type: Boolean

Whether the status is in the 2xx range.

Headers

Type: Map

The response and content headers together, in one case-insensitive Map. A header sent more than once is joined with ", ", as HTTP itself defines.

Text

Type: String

The body decoded as text, using the charset the response names, and UTF-8 when it names none or names one this platform does not know.

Body

Type: Buffer

The body's raw bytes.

Url

Type: String

Where the response came from, which differs from the requested URL after a redirect. Redirects are followed automatically.

Json()

Type: Any

The body decoded as JSON, the same as Json.Decode(Res.Text). Call Json.Decode directly to pass its CaseSense or NullValue options. A body which is not well-formed JSON throws a ValueError.

ToClr()

Type: Clr

The underlying HttpResponseMessage, whose body has already been read.

Errors

A non-2xx status is not an error. The server answered, and the body of a failed request is usually where the reason is; IsSuccess is the test. Treating a 404 as an exception would put that body out of reach without a try block.

What does throw:

  • A transport failure — the host does not resolve, the connection is refused or drops, TLS fails — as an OSError.
  • An elapsed Timeout, as a TimeoutError.
  • An empty or non-absolute URL that no BaseUrl completes, an empty method, an unusable header or proxy value, an unrecognized option key, or a session option given per request, as a ValueError.
  • A transfer stopped by OnData, as the Error Await throws for canceled work.

Examples

A request and its JSON answer.

#Import "Ks" { Http }

Res := Http.Get("https://api.github.com/repos/keysharp-org/Keysharp")
if Res.IsSuccess
    MsgBox Res.Json()["stargazers_count"]
else
    MsgBox "HTTP " Res.Status ": " Res.Text

A session, whose headers and cookies apply to each of its calls.

#Import "Ks" { Http, Url, Await }

Api := Http({BaseUrl: "https://example.com/api/", Headers: Map("Authorization", "Bearer " Token)})
Api.Post("items", , {Json: {Name: "widget", Count: 2}})
Items := Api.Get("items?q=" Url.Encode(Query)).Json()

; Two requests at once.
Both := Await(Task.WhenAll(Api.GetAsync("items"), Api.GetAsync("users")))

Streaming to a file with a progress bar, which is what Download does internally.

#Import "Ks" { Http }

Gui1 := Gui(), Bar := Gui1.Add("Progress", "w300"), Gui1.Show()
File := FileOpen("big.iso", "w")
Http.Get(Url, {OnData: (Chunk, Received, Total) =>
    (File.RawWrite(Chunk), Bar.Value := Total > 0 ? 100 * Received / Total : 0, 0)})
File.Close()

What is not included

There is no WebSocket, HTTP server, multipart body, cookie inspection, redirect switch or retry policy. System.Net.WebSockets and System.Net.Sockets are reachable through Clr on every platform, and Handler covers the rest of what the .NET stack can be told to do.
