Font Object

class Font extends Object

A font as a value object. It carries the same settings Gui.SetFont takes, but as named properties which can be read, changed and passed around, and it names the families the platform actually uses for its own interface.

This class is exported by the KS module.

Every property is optional. An unset one reads as an empty string and contributes nothing to Options, so a Font describes only what it was told and leaves the rest to whatever applies it.

Call

FontObj := Font(Options, FontName)

Creates a Font from the two arguments Gui.SetFont takes, in the same order and with the same meaning.

Options

Type: String

Zero or more space-delimited option tokens: sSize, wWeight, qQuality, cColor, and the keywords bold, italic, underline, strike and norm.

FontName

Type: String

The font family name, such as "Segoe UI". The family is separate from Options because a family name may contain spaces.

Properties

PropertyDescription
NameThe font family name.
SizePoint size, in the same convention scripts use everywhere else.
ColorText color as a 6-digit RRGGBB string, like Gui.BackColor. Accepts a color name, a hex string or an integer when assigned.
WeightWeight as the wN option takes it: 400 is normal, 700 is bold.
BoldA view over Weight as a truth value. Reading it is Weight >= 700; assigning sets the weight to 700 or 400.
ItalicWhether the font is italic.
UnderlineWhether the font is underlined.
StrikeWhether the font is struck through.
QualityRendering quality as the qN option takes it. It is carried so that an option string round-trips unchanged; nothing acts on it yet.
OptionsThe set properties rendered back as an option string SetFont accepts, such as "s10 w700 cFF0000 italic". The family is not part of it, so the round trip is SetFont(FontObj.Options, FontObj.Name).

Standard Families

These class properties each return a new Font describing a family the platform itself uses, so a script can match the desktop instead of hard-coding a name which may not be installed.

PropertyDescription
Font.UiThe platform's standard interface font, queried from the system so it follows the desktop theme.
Font.EmojiThe family the platform draws color emoji with, at the UI font's size.
Font.MonospaceThe platform's fixed-pitch family, at the UI font's size. The first of the usual candidates which is actually installed is used, so it stays useful on a stripped-down system.
Font.GuiDefaultThe font a new Gui starts with. This is AutoHotkey's default rather than the platform interface font, so that a ported script lays out identically.
Font.FamiliesAn Array of the family names installed on the system, sorted alphabetically.

Note: On Linux and macOS the system cannot be asked for its interface font until the first window exists, so Font.Ui falls back to the usual family for the platform before then.

Remarks

A Gui and each of its controls expose a Font property returning a detached snapshot: changing the returned object does not change the control. Assign it back, or pass it to SetFont, to apply it.

Because Options renders only what was set, a Font is also the way to change one aspect of a font without restating the others.

Examples

Builds a font and applies it to a GUI.

#Import "Ks" { Font }

MyFont := Font("s12 bold cNavy", "Segoe UI")
MyGui := Gui()
MyGui.SetFont(MyFont.Options, MyFont.Name)
MyGui.Add("Text", , "Heading")
MyGui.Show()

Enlarges a control's existing font without restating the rest of it.

#Import "Ks" { Font }

MyGui := Gui()
Ctl := MyGui.Add("Text", , "Some text")

MyFont := Ctl.Font   ; a detached snapshot
MyFont.Size := MyFont.Size + 4
MyFont.Bold := true
Ctl.Font := MyFont   ; assign it back to apply it

MyGui.Show()

Uses the platform's own interface and monospace families.

#Import "Ks" { Font }

MyGui := Gui()
MyGui.SetFont(Font.Ui.Options, Font.Ui.Name)
MyGui.Add("Text", , "Matches the desktop theme")

Mono := Font.Monospace
MyGui.SetFont(Mono.Options, Mono.Name)
MyGui.Add("Edit", "w300 r5", "Fixed-pitch text")

MyGui.Show()
