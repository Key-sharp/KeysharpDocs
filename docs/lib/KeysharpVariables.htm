Keysharp Built-in Variables

These accessors are exported by the KS module. Import only the names a script uses.

Thread Identity

A_ThreadId consists of a 48-bit script-wide creation sequence and a 16-bit zero-based pseudo-thread stack index. A_ThreadId & 0xFFFF retrieves the stack index; auto-execute is index 0 on its real thread.

An ID is nearly unique for the script's lifetime but valid only while its pseudo-thread is active. An exact ID can be targeted only from its owning real thread. See Exit for targeted termination.

Millisecond Date Values

A_NowMs and A_NowUtcMs can be used with DateAdd and DateDiff by specifying "L" as the time unit.

Screen Scale

A_ScreenScale reports how large deliberately authored UI sizes should be drawn on the primary screen: 1.0 is 100%, 1.5 is 150%.

Note: This is not a screen-coordinate conversion factor. Applying it to an absolute position produces a wrong result.

The value describes the primary monitor only. Code which spans monitors of differing scale should call MonitorGetScale for the monitor it is working with.
