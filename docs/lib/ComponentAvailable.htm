ComponentAvailable

Reports whether an optional first-party script-processing unit is available.

This function is exported by the KS module.

IsAvailable := ComponentAvailable(Capability)

Parameters

Capability

Type: String

Specify "parser" or "compiler". "parsing" and "compilation" are accepted as synonyms.

Return Value

Type: Integer (Boolean)

Returns 1 if the installed or embedded unit is compatible and can be loaded, otherwise 0. The check loads the requested unit, so checking "compiler" can also load Roslyn.

Error Handling

A ValueError is thrown if Capability is not a recognised name.

Remarks

parser and compiler are stable IDs for Keysharp's optional first-party deployment units; this interface does not select arbitrary third-party providers. Compiled scripts normally contain only the runtime. A statically visible call to RunScript or ParseScript causes the compiler unit to be included automatically. The component build options can explicitly include or exclude either unit.

Use --without-compiler when compiling capability-gated code which should continue to operate without dynamic compilation.

Examples

Uses dynamic compilation only when the compiler is present.

#Import "Ks" { ComponentAvailable, RunScript }

if ComponentAvailable("compiler")
    RunScript('FileAppend "compiled dynamically``n", "*"')
else
    FileAppend "compiler not installed``n", "*"
