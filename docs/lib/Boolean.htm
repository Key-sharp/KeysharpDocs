Boolean

class Boolean extends Integer

The type of a truth value. Every operator that yields one yields a Boolean: a comparison, a negation, and Map.Has. The true and false keywords are Boolean values too.

A Boolean behaves as the Integer 1 or 0 in every other respect, so no existing code has to change to account for it.

The class is exported by the KS module:

#Import "Ks" { Boolean }

Note: Only the name comes from the KS module. Boolean values need no import — they are produced by ordinary operators in any script.

AutoHotkey v2 has no boolean type, and the global namespace is AutoHotkey's, which is why the name lives in KS rather than alongside Integer and Float.

Behaves as an Integer

Boolean extends Integer because that is how a truth value behaves throughout the language:

  • Type reports "Integer", not "Boolean".
  • Value is Integer and Value is Number are true.
  • It compares equal to 1 and 0, and does arithmetic as 1 and 0.
  • It converts to the strings "1" and "0".
  • If and the ternary operator test it correctly.
#Import "Ks" { Boolean }

MsgBox Type(true)        ; Integer
MsgBox Type(1 > 0)       ; Integer
MsgBox true == 1         ; 1
MsgBox true + 1          ; 2
MsgBox "" true           ; 1

Testing for a Boolean

Value is Boolean is what distinguishes a truth value from an ordinary Integer. Since a Boolean compares equal to 1 or 0 and Type names it "Integer", no comparison can do it.

#Import "Ks" { Boolean }

MsgBox (1 > 0) is Boolean    ; 1
MsgBox (1 > 0) is Integer    ; 1
MsgBox 1 is Boolean          ; 0
MsgBox 1 is Integer          ; 1

This matters when the shape of data is being validated rather than merely read: a plain if (Value) accepts 1, "yes" and true equally.

Where the distinction shows in output

Json.Encode writes a Boolean as JSON true or false, and an Integer as a number. This is the one place the difference is visible outside a type test.

#Import "Ks" { Json }

MsgBox Json.Encode(Map("ok", 1 > 0))   ; {"ok":true}
MsgBox Json.Encode(Map("ok", 1))       ; {"ok":1}
MsgBox Json.Encode(Map("ok", true))    ; {"ok":true}

It is also what lets JSON booleans survive a decode followed by an encode: Json.Decode produces Booleans for true and false.

Boolean()

Converts a value to a Boolean, deciding it exactly as If would.

Value := Boolean(Expression)

Parameters

Expression

Type: Any

The value to convert.

Return Value

Type: Boolean

Returns true if Expression is truthy, else false. An empty string, 0 and "0" are false; any object, any non-empty non-numeric string, and any non-zero number are true.

Errors

An UnsetError is thrown if Expression is unset, exactly as testing an unset variable with If throws.

Examples

Every truth-valued operator produces a Boolean.

#Import "Ks" { Boolean }

MsgBox (1 > 0) is Boolean              ; 1
MsgBox (1 = 1) is Boolean              ; 1
MsgBox (!0) is Boolean                 ; 1
MsgBox Map("a", 1).Has("a") is Boolean ; 1
MsgBox InStr("abc", "b") is Boolean    ; 0, InStr returns a position

Normalising a setting that may arrive as a number, a string or a real Boolean.

#Import "Ks" { Boolean, Json }

Config := Json.Decode(FileRead("config.json"))

; Accepts true, 1 and "yes" alike.
Enabled := Boolean(Config["enabled"])

; Writes a real JSON boolean back out, whatever the file contained.
Config["enabled"] := Enabled
FileOpen("config.json", "w").Write(Json.Encode(Config, 2))

Rejecting a setting that is not genuinely a boolean, which a plain truth test cannot do.

#Import "Ks" { Boolean, Json }

Config := Json.Decode('{"pinned": 1}')

if !(Config["pinned"] is Boolean)
    MsgBox "pinned must be true or false"   ; shown: it is the number 1
