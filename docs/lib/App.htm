App Object

class App extends Object

The running application: its identity, its invocation and its exit state.

See #App, the directive that declares these values.

This class is exported by the KS module.

#Import "Ks" { App }
MsgBox App.Title " " App.Version

Importing the module instead of the member reaches the same class through it:

#Import "Ks"
MsgBox Ks.App.Title " " Ks.App.Version

Note: There is one application per process, so this class has no instances and every member is used directly on the class. Calling App() throws an Error. Every member is read-only; assigning to one throws a PropertyError.

#App declares what must be fixed before the application starts; App reports the running assembly. Not every #App key has an App member; see Settings With No App Member.

Assembly Metadata

Value := App.Title

Nine strings, each read from the .NET assembly attribute the matching #App key sets.

PropertyDescription
App.NameThe assembly's identity, which always has a value: without the Name key it is the script's file name without its extension, or * when the script was compiled from standard input.
App.TitleThe application title: assembly metadata, shown on Windows in a compiled executable's file properties. It is not the default dialog or window title, which remains A_ScriptName.
App.DescriptionThe application description.
App.ConfigurationThe build configuration label, such as Release.
App.CompanyThe company name.
App.ProductThe product name.
App.CopyrightThe copyright notice.
App.TrademarkThe trademark notice.
App.VersionThe application's own version, which the Version key stamps onto both the assembly and the file version. See Three versions.

A key which was never declared reads as an empty string, in both compatibility modes, rather than raising. App.Name is never blank.

Note: App.Company != "" is the supported test for whether a key was declared, since #App rejects an empty declared string at compile time. HasOwnProp is not: it reports every declared property present, so App.HasOwnProp("Company") is true whether or not the key was ever set.

Three versions

Three separate versions are readable, and only the first is the application's.

ValueReports
App.VersionThe version of the application itself, declared by #App.
A_AhkVersionThe AutoHotkey compatibility level targeted.
Ks.A_KsVersionThe Keysharp engine build.

App.Version is an assembly version: two to four decimal components, each from 0 through 65534. That format has no room for a semantic-versioning prerelease tag such as 1.2.0-beta.1.

Invocation

CommandLine

Line := App.CommandLine

The command line this process was launched with: the host executable followed by every argument, with any token containing a space wrapped in quotes. Quoting is normalized rather than preserved byte for byte.

In an interpreted run, token 0 is the Keysharp executable — the same path as A_AhkPath — and any engine switches precede the script path:

"C:\Program Files\Keysharp\Keysharp.exe" --errorstdout C:\Tool.ks report.csv

Only the last token came from the script's own caller. A compiled application reports its own executable. The script's own arguments are A_Args.

Exit State

Both members report an exit in progress to code which is not an OnExit callback — a __Delete, a timer, a library — and stay readable through the whole teardown.

ExitReason

Reason := App.ExitReason

Why the application is exiting: the same string an OnExit callback receives as its first parameter, from the list of exit reasons.

It is non-empty from the moment the exit begins, including while the OnExit callbacks run, and an empty string when no exit is in progress or once a callback cancels one.

ExitCode

Code := App.ExitCode

The exit status this process will return to whoever launched it, as an Integer. Exit and ExitApp are how a script sets it; the runtime also picks it on the script's behalf, using 2 for a critical error and 1 for a failed auto-execute section or an uncaught exception.

Inside an OnExit callback, the pending code for that exit is the callback's second parameter. App.ExitCode reports the status currently armed, which within a callback is still the previous value, since the callback may yet cancel the exit. After the callbacks, it is the status the process will return.

Settings With No App Member

The remaining #App keys, and the startup directives stored alongside them, have no App member.

Declared byRead instead
#App Icon, #TrayIcon, #NoTrayIconA_IconFile, A_IconNumber, A_IconHidden and Ks.A_NoTrayIcon, which report a run-time override. A_IconFile is blank while the declared or embedded icon is in use, so the declared icon is not readable from a script.
#App GuiThemeKs.A_GuiTheme, which reports the theme windows are drawn with and can also be assigned. The key only chooses what it starts as.
#App ConsoleApp, #ErrorStdOutNothing. These are compiler decisions and leave no runtime state.
#SingleInstanceNothing. --force and --restart override the declared mode, and the guard exists only when the directive is present.
#App HookMutexNameNothing. It is a cross-process identifier which no script consumes, and an undeclared one is the literal Keysharp.
#App FilesNothing. Payloads are embedded only when compiling to a .cks or an executable; FileInstall copies the live file otherwise.

The declared values themselves, including these, can be read without running the script: a compiled assembly carries them as the Keysharp.App.json resource.

Remarks

Under a host which supplies its own assembly, the nine metadata members can report that host's attributes. When Keysharp is embedded in another .NET application there may be no script assembly to read, and the members return the host's values or the Keysharp runtime's own. Nothing distinguishes that from a declared value, and the empty-string test does not catch it. This does not arise when a script is run or compiled normally.

A local variable shadows an imported class name, and variable names are not case-sensitive, so app := Gui() in a function makes every later App.Title in that scope read the local instead. Importing the module and reaching the class as Ks.App avoids it.

Examples

Builds an about box from the application's own metadata.

#App {
    Title: "Snippet Manager",
    Company: "Acme Corp",
    Version: "1.2.0",
}
#Import "Ks" { App }

MsgBox App.Title "`nVersion " App.Version "`n" App.Company

Tests whether a key was declared. An undeclared key reads as an empty string, which is falsy.

#Import "Ks" { App }

if (Company := App.Company)
    MsgBox "Published by " Company
else
    MsgBox "No company declared."

Reads the exit in progress from an object's __Delete, which runs during teardown and so receives none of the OnExit callback's parameters.

#Import "Ks" { App }

Keeper := Session()
ExitApp 3

class Session
{
    __Delete()
    {
        FileAppend "Closing: " App.ExitReason " (" App.ExitCode ")`n", "*"
    }
}
