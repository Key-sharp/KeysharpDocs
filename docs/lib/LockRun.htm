LockRun

Calls a function while holding a lock on an object.

This function is exported by the KS module.

Result := LockRun(LockObject, Callback , Arguments*)

Calls using the same LockObject execute their callbacks one at a time. The return value is the callback's return value.

Parameters

LockObject

Type: Object

The object to lock on. Create one for the purpose, for example lock := Object(), and share that same object between the threads which must not run the callback concurrently.

A number cannot be used and throws TypeError: each call would lock a distinct temporary, providing no exclusion at all.

Callback

Type: Function Object

The function to call while the lock is held.

Arguments

Any arguments to pass to Callback.

Warning: A string is accepted but is a poor lock. Identical string literals are shared process-wide, so unrelated parts of a script which both lock on "" serialize against each other.

Examples

Serializing updates to a shared total.

#Import "Ks" { RealThread, LockRun }

global lock := Object(), total := 0
workers := []

Loop 4
    workers.Push(RealThread(AddUp, 1000))

for w in workers
    w.Wait()

MsgBox total

AddUp(n) {
    Loop n
        LockRun(lock, () => total += 1)
}
