RequestCapabilities

Requests platform permissions or queries their current state.

This function is exported by the KS module.

Status := RequestCapabilities(Capabilities*)

Parameters

Capabilities

Zero or more capability-name strings. Each string can contain names separated by commas or spaces; arrays of names are also accepted. If no capability is specified, the function returns the current state of every capability without prompting.

Capability Names

NamePurpose
InputMonitoringMonitor keyboard and mouse input, including hotkeys and hotstrings.
InputControlSynthesize or suppress input with Send, Click, BlockInput and related APIs.
WindowMonitoringInspect windows and subscribe to window events.
WindowControlChange windows, including moving, activating and closing them.
ScreenCaptureCapture pixels with PixelGetColor, ImageSearch or Image.
AudioCaptureReserved permission scope; granting it does not enable an audio-capture API.
CameraCaptureReserved permission scope; granting it does not enable a camera-capture API.
ClipboardMonitoringRead or observe the clipboard through a supported backend.

Names are case-insensitive. Aliases are not accepted.

Return Value

Type: Object

Returns an object with one property per capability. Each value is "Granted", "Denied", "NotApplicable" or "Unsupported". The IsGranted property is 1 only if every requested capability was granted or is not applicable.

Remarks

Linux

On Linux, scopes handled by the same native authority are requested together. Input and desktop requests may need separate prompts, and system installations share the InputControl grant. Grants belong to the host executable, so scripts using the same interpreter share them; a later request for additional scopes may prompt again. These rules apply on X11 and Wayland. See Linux permissions.

Use #Requires capability when permissions are needed from startup. Use RequestCapabilities when a script needs to choose when to prompt or inspect individual results.

Examples

#Import "Ks" { RequestCapabilities }
Caps := RequestCapabilities("InputMonitoring", "ScreenCapture")
if Caps.IsGranted
    MsgBox "All permissions granted"
MsgBox Caps.ScreenCapture

; Query without prompting.
Current := RequestCapabilities()
