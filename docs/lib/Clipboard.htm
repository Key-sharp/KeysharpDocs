Clipboard Object

class Clipboard extends Object

Reads and writes the system clipboard as text, an image, a file list, HTML, RTF, or any format the platform itself advertises.

This class is exported by the KS module.

Note: There is one clipboard per session, so this class has no instances and every member is used directly on the class. Calling Clipboard() throws an Error.

Every getter returns an empty string when the clipboard does not hold that content. An empty string is falsy, so if (Files := Clipboard.Files) is the intended pattern.

A_Clipboard, ClipboardAll, ClipWait and OnClipboardChange continue to work unchanged and remain the AutoHotkey-compatible surface. This class is additive.

Typed Content

These properties are the portable surface. Each maps to whichever format names the current platform uses for that kind of content.

Text

Value := Clipboard.Text
Clipboard.Text := Value

The clipboard's text, identical to A_Clipboard. Assigning an empty string clears the clipboard entirely.

Image

Picture := Clipboard.Image
Clipboard.Image := Source

Gets an Image, or an empty string if the clipboard holds no image.

Source accepts everything the Image constructor accepts: an Image, a file path, a native bitmap handle, or an "HBITMAP:" specifier. Because the setter takes an Image directly, a captured or generated image no longer has to be written to a file first.

Image.FromClipboard is an alias of this property's getter.

Files

Paths := Clipboard.Files
Clipboard.Files := Paths

The copied files as an Array of paths, or an empty string if the clipboard holds no file list. The setter accepts an Array of paths or a single path, and publishes them with copy semantics.

Cut semantics (so that a file manager moves rather than copies on paste) are desktop-specific and are not implemented.

Html

Markup := Clipboard.Html
Clipboard.Html := Markup

The clipboard's HTML as the fragment — the markup itself. On Windows, clipboard HTML is stored inside a CF_HTML envelope of byte offsets; this property adds that envelope on write and strips it on read, so markup assigned here pastes correctly into applications such as word processors. To read or write the raw envelope, use GetData or Set with the native format name.

Rtf

Source := Clipboard.Rtf
Clipboard.Rtf := Source

The clipboard's Rich Text Format source, or an empty string if the clipboard holds none.

State

IsEmpty

Empty := Clipboard.IsEmpty

Returns 1 (true) if the clipboard holds nothing in any format, or 0 (false) otherwise. This is derived from the platform's own format enumeration, so private and application-registered formats count as content.

Formats

Names := Clipboard.Formats

An Array of every format the clipboard currently advertises, under the names the platform itself uses: "HTML Format" and "FileDrop" on Windows, "text/html" and "text/uri-list" elsewhere.

Note: These names are deliberately not normalized across platforms. A script that reads or writes them is platform-specific by construction; the typed properties above are the portable equivalent.

Has

Present := Clipboard.Has(Kind)

Returns 1 (true) if the clipboard holds the given content, or 0 (false) otherwise.

Kind is one of the portable kind names "Text", "Image", "Files", "Html" or "Rtf" (matched without case sensitivity), or any platform-native format name from Formats. A kind name takes precedence when it collides with a native name.

Use this rather than reading a property when only presence matters, since Image would copy the whole bitmap just to answer the question.

Clear

Clipboard.Clear()

Empties the clipboard.

Native Formats

These members reach formats the typed properties do not cover, such as an application's private format.

GetData

Data := Clipboard.GetData(Format)

Returns a Buffer holding one format's bytes exactly as the platform stores them, or an empty string if the clipboard does not hold that format. Format is a platform-native name.

Decoding the bytes is the caller's responsibility; for a text-like format, use StrGet with the encoding that format specifies.

Set

Clipboard.Set(Formats)

Publishes several formats in a single clipboard transaction, so they coexist instead of overwriting one another and the change is reported once.

Formats is an object or a Map. Each key is a kind name ("Text", "Image", "Files", "Html", "Rtf") or a platform-native format name. Each value is a String, a Buffer, an Image, or an Array of paths for Files. A String given for a native format is written as UTF-8.

A Map is accepted as well as an object because an object literal's keys must be identifiers, so a format name containing a space — such as "HTML Format" — can only be written as a Map key.

Saving and Restoring

All

Saved := Clipboard.All
Clipboard.All := Saved

Gets a ClipboardAll holding every format currently on the clipboard, and restores one. This is the same operation as ClipboardAll() followed later by A_Clipboard := Saved, written so that the round trip is visible at both ends.

Assigning anything other than a ClipboardAll throws a TypeError.

Waiting and Change Events

Wait

Arrived := Clipboard.Wait(Timeout, WaitFor)

Waits for clipboard content, returning 1 (true) if it arrived or 0 (false) on timeout. If Timeout is omitted, this waits indefinitely; otherwise it is a number of seconds and may be fractional.

WaitFor behaves exactly as it does for ClipWait: omitted or 0 waits for text or files, and 1 waits for content of any kind. It additionally accepts a kind name — "Text", "Any", "Image", "Files", "Html" or "Rtf". ClipWait accepts those names too.

OnChange

Hook := Clipboard.OnChange(Callback , Count)

Calls Callback whenever the clipboard's content changes, and returns a ClipboardHook object controlling the subscription.

The callback is called as Callback(Hook, Type), where Type is 0 if the clipboard is now empty, 1 if it holds text or files, or 2 for anything else. Count defaults to -1 (unlimited); any other number stops the hook automatically after that many calls.

Registrations made here and through OnClipboardChange share one native clipboard monitor. Prefer this method when the callback is a closure or bound function: unregistering through OnClipboardChange requires passing the identical function object back, whereas the hook can stop itself.

ClipboardHook Object

Carries the same surface as a WinEvent hook.

MemberDescription
Stop()Cancels the subscription so the callback no longer fires.
Pause(NewState)Pauses (1), unpauses (0) or toggles (-1) this hook, returning the resulting state. A paused hook stays registered but does not fire.
PausedGets or sets whether the hook is paused.
IsActiveTrue while the subscription is still receiving events.
CountRemaining number of times the callback will fire; -1 means unlimited.
CallbackThe function this hook calls.

The subscription also stops when the hook is collected, but garbage-collection timing is unpredictable; call Stop() when the exact moment matters.

Platform Support

MemberWindowsLinuxmacOS
Text, IsEmpty, Clear, Formats, Has, GetData, Wait, OnChangeFullFullUnverified
Files, Html, RtfFullFullUnverified
ImageFullWriting works; reading an image back has not been confirmed on a desktop sessionUnverified
Set, AllFullFull on X11 and on compositors exposing a data-control protocol; a single representation under a shell-extension Wayland sessionUnverified

Under a Wayland session served through a desktop shell extension (such as Cinnamon or Muffin), the compositor's selection source can advertise only one type. Set and All therefore restore the single most useful representation rather than every format, which is the same limitation ClipboardAll documents there.

macOS rows are unverified rather than unsupported: the macOS clipboard backend has not been exercised on a macOS machine.

Examples

Reads and replaces the clipboard's text.

#import "Ks" { Clipboard }

Clipboard.Text := "Hello"
MsgBox Clipboard.Text

Copies the selected text without losing what was on the clipboard.

#import "Ks" { Clipboard }

Saved := Clipboard.All
Clipboard.Clear()
Send "^c"
if Clipboard.Wait(2)
    MsgBox "Selection: " Clipboard.Text
Clipboard.All := Saved

Publishes rich text with a plain-text fallback, in one transaction, so a word processor pastes the formatting and a plain editor pastes the text.

#import "Ks" { Clipboard }

Clipboard.Set({ Text: "Hello", Html: "<b>Hello</b>" })

Lists the files copied in a file manager.

#import "Ks" { Clipboard }

if (Files := Clipboard.Files)
    for Path in Files
        MsgBox Path

Puts a screen capture straight on the clipboard.

#import "Ks" { Clipboard, Image }

Clipboard.Image := Image.FromRect(0, 0, 800, 600)

Watches the clipboard for three changes, then stops.

#import "Ks" { Clipboard }

Hook := Clipboard.OnChange(Report, 3)

Report(ThisHook, Type)
{
    ToolTip "Clipboard changed, type " Type ", " ThisHook.Count " left"
}
