RealThread Object

class RealThread extends Object

Runs callbacks on a real operating-system thread, each with its own event loop. This is distinct from the cooperative script threads that the rest of the language schedules, which are described by the Thread object.

This class is exported by the KS module.

#Import "Ks" { RealThread }
worker := RealThread(Sum, 1, 100)
worker.Wait()
MsgBox worker.Result

Sum(from, to) {
    total := 0
    Loop to - from + 1
        total += from + A_Index - 1
    return total
}

Kinds of real thread

Three kinds of object share this class, and they differ only in whether there is a body to wait for:

Obtained fromDescription
RealThread(Callback, Arguments*)A worker this class started. The only kind that can be waited on, continued or exited.
RealThread.MainThe script's main thread.
A_RealThreadThe thread the calling code is on: one of the above, or an adopted thread when script code runs on some other thread.

On the main and adopted kinds, Wait, ContinueWith and Exit throw TargetError, because there is no body of their own to wait for or unwind. Everything else behaves the same, which is what makes RealThread.Main.Post(Callback) the supported way to move work back onto the main thread.

Exactly one object exists per real thread, so == identifies which kind one is: A_RealThread == RealThread.Main is true on the main thread.

Call

Worker := RealThread(Callback , Arguments*)
Worker := RealThread.Call(Callback , Arguments*)

Starts Callback on a new real thread and returns its RealThread object. Any Arguments are passed to Callback.

The thread ends when its body returns and it has nothing left to serve. A body that registers a timer, hotkey, callback or window event keeps its thread alive to serve them; use Exit to shut such a thread down.

Note: An uncaught error in Callback is reported on the thread where it happened, in the same way as an error in a timer or hotkey. It is not delivered to whoever calls Wait; IsFailed becomes true instead.

Main

MainThread := RealThread.Main

The script's main thread. Use it to move work onto the main thread from a worker:

RealThread.Main.Post(() => MsgBox("Shown on the main thread"))

Post

Worker.Post(Callback , Arguments*)

Queues Callback on the thread and returns immediately without waiting for it to run.

Send

Result := Worker.Send(Callback , Arguments*)

Runs Callback on the thread, waits for it, and returns its result. The calling thread keeps processing its own events while it waits.

The target thread runs the callback the next time it processes events, so a thread busy in a long computation that never yields will not answer until it does. The callback runs as a thread of its own on the target, so a target which is Critical or has reached #MaxThreads refuses it and this raises an error, rather than waiting for the target to become interruptible.

Wait

Finished := Worker.Wait(Timeout)

Waits for the thread to finish, processing events while it waits, and returns 1 (true) if it finished or 0 (false) if Timeout elapsed first. Timeout is in milliseconds; omit it to wait indefinitely. Read Result for the value the body returned.

A thread cannot wait on itself; doing so throws TargetError.

ContinueWith

Continuation := Worker.ContinueWith(Callback , Arguments*)

Starts Callback on a new real thread once this one finishes, and returns the continuation's RealThread object.

Calling Exit on the continuation before it starts cancels it, so its callback is not run.

Exit

Worker.Exit(ExitCode)

Asks the thread to shut down. Work already queued on it is abandoned, a script thread running on it unwinds when it next processes events, and its event loop then stops. This is cooperative and does not asynchronously abort running code. Shutting down a thread that has already ended is not an error.

Called on the thread itself (A_RealThread.Exit()), the current script thread exits immediately and the call does not return.

If Exit ends the worker before its body returns, IsCanceled becomes true. If the body already returned successfully and only its persistent event loop remained, Exit preserves IsSuccessful and Result.

ExitCode

Type: Integer

If omitted, it defaults to 0. Otherwise, the process exit code to apply to the script threads being exited.

Properties

Id

Type: Integer

The managed ID of the backing operating-system thread.

IsActive

Type: Boolean

True while the thread has not finished. This tracks the same moment Wait waits for, so it remains true while a worker serves timers or callbacks after its body returned. It is also true before a ContinueWith worker has started. For the main and adopted kinds, IsActive is always true.

IsSuccessful

Type: Boolean

True only after the worker finishes successfully.

IsFailed

Type: Boolean

True only after the worker finishes because of an error.

IsCanceled

Type: Boolean

True only when Exit ends the worker before its body returns.

Result

The value the thread's body returned after successful completion. An empty string otherwise.

Threads

Type: Array

The active Thread objects of this real thread, oldest first, so Threads[1] is the one that has been running longest. The array is a snapshot taken when the property is read, and is empty while the thread sits idle in its event loop.

Remarks

Exactly one of IsActive, IsSuccessful, IsFailed and IsCanceled is true. On the main and adopted kinds, IsActive remains true and the three terminal properties remain false.

State shared between real threads requires synchronization. Use LockRun or another appropriate design when callbacks mutate shared objects.

Settings that are per script thread — CoordMode, SendMode, SetKeyDelay, A_LastError and the rest — are also per real thread, so a worker starts from the script's defaults and its changes do not affect the main thread.

Examples

Doing slow work off the main thread and reporting back to it.

#Import "Ks" { RealThread, A_RealThread }

worker := RealThread(Crunch, 30000000)

Crunch(iterations) {
    total := 0
    Loop iterations
        total += A_Index
    ; Post returns immediately; the main thread shows the result when it next processes events.
    RealThread.Main.Post(Report, total)
    return total
}

Report(total) {
    MsgBox "Total: " total
}

A long-lived worker that serves requests until it is shut down.

#Import "Ks" { RealThread }

service := RealThread(Serve)

; Send runs on the worker and returns its value.
MsgBox service.Send(() => "answered by thread " A_RealThread.Id)

service.Exit()
service.Wait()

Serve() {
    ; Keeps the worker's event loop alive so Post and Send have somewhere to land.
    SetTimer(() => 0, 1000)
}
