Audio Object

class Audio extends Object

Plays sounds from files or memory, discovers and operates audio devices, controls what other applications are playing, observes levels, and records from a microphone or from what an output device is playing.

This class is exported by the KS module:

#Import "Ks" { Audio }

Note: There is one audio system per script, so this class has no instances and its own members are used directly on the class. Calling Audio() throws an Error.

Audio is also the container for the eight related types this page documents. They are reached through it — Audio.Clip, Audio.Device, Audio.Output, Audio.Playback, Audio.Session, Audio.Meter, Audio.Recorder and Audio.Recording — and importing Audio introduces no other names.

Compared with the Sound functions

The Sound functions are the AutoHotkey-compatible surface and are unchanged by this class. The two solve different problems:

Sound functionsThis class
SoundPlay plays one file at a time through the platform's own player.Decodes once into a reusable clip and mixes several sounds at once through one stream, so a repeated sound neither re-decodes nor cuts off the previous one.
SoundSetVolume and its relatives select a device by a fuzzy name or number, and control that endpoint.Every operation names an exact device by its opaque Id, or takes the current default explicitly.
No handle to a sound that is playing.Audio.Play returns a playback whose volume, pan, position, loop and mute can be changed while it runs.
No application-level control, metering or capture.Sessions, meters and recorders.

The relationship is the one A_Clipboard has with Clipboard.Text: the compatible function keeps its own selector and semantics, and this class is additive.

Conventions

These hold for every member on this page.

SubjectRule
LevelsVolume and peak are finite numbers from 0 through 100. Pan is finite, from -100 (full left) through 100 (full right).
TimesDurations and positions are milliseconds and may be fractional.
AbsenceA value which is not yet known, does not apply, or has no default reads as an empty string. Enumerations return an empty Array and counts return 0 instead.
Tokens and namesEvery documented string token, device name and executable name is matched without case sensitivity, and getters return the canonical casing shown here. An opaque Id is compared exactly, because it is backend identity.
Sample formats"Unsigned8", "Signed16", "Signed24", "Signed32" or "Float32".
Sample rate and channels8000 through 192000 Hz; 1 or 2 channels.

Selecting a device

Everywhere a device is accepted it may be an Audio.Device, an exact Id, an exact and unique Name, or an empty string for the platform's current default. A name matching several devices throws a ValueError listing their ids; a selector matching none throws an OSError.

Error handling

ResultSituation
TypeErrorA value of the wrong kind, such as a path where a Clip is required.
ValueErrorAn unknown token, a non-finite number, a value outside a documented range, malformed PCM, an ambiguous device name, or an operation on a disposed object. Setters never clamp; use Min and Max before assigning.
OSErrorA capability this host does not provide, a denied permission, or a device, decode or write failure. The message names the missing capability and a concrete next step.
Empty stringA bounded refusal from Audio.Output.Play, and an absent default, match or result.

Check the capability first where a script must not raise: each probe answers without a native call.

Audio

Capability probes

Each of these is a read-only true or false. They read a published snapshot rather than calling into the platform, so they never open a device and never prompt for permission.

PropertyDescription
IsPlaybackSupportedWhether this host has a playback implementation at all. It says nothing about whether a speaker is attached.
IsOutputAvailableWhether a usable output device is present. A supported host with no speakers answers false here and true to IsPlaybackSupported.
IsInputAvailableWhether a usable input device is present.
IsDeviceChangeSupportedWhether OnDeviceChange can subscribe to device arrivals, removals and default changes.
IsSessionControlSupportedWhether this host can enumerate and control other applications' audio.
IsMeteringSupportedWhether an Audio.Meter can observe a device or session level.
IsMicrophoneCaptureSupportedWhether a microphone or other input device can be recorded.
IsSystemAudioCaptureSupportedWhether what an output device is playing can be recorded.

IsFormatSupported

Supported := Audio.IsFormatSupported(Format)

Returns 1 (true) if Load can decode that container, or 0 (false) otherwise. Format is a token or an extension, with or without the leading dot, such as "wav" or ".WAV". This never inspects a file.

Note: WAV is decoded by a managed reader on every platform, so it is always supported. Every other container depends on a codec the host already ships, and this reports what that host's decoder actually initialized with rather than a fixed list. Windows uses Media Foundation and reports mp3, m4a, aac, wma and flac; Linux uses libsndfile when it is installed, and otherwise ffmpeg when it is on PATH; macOS uses ExtAudioFile. Ogg and Opus are not claimed on Windows or macOS, because neither ships a decoder for them. Where a container is unsupported, convert the file to WAV or read its samples yourself and use FromPcm.

Load

Clip := Audio.Load(Path)

Decodes a file into a reusable, immutable Audio.Clip. A relative path resolves once, against the current A_WorkingDir, at the moment of the call.

An empty path, a path containing a NUL, or a syntactically invalid path throws a ValueError before any I/O. A missing or unreadable file, an invalid container, and a format this host cannot decode each throw an OSError naming the file.

FromPcm

Clip := Audio.FromPcm(Data, SampleRate , Channels, SampleFormat)

Copies headerless PCM out of a Buffer into an immutable clip. The copy is synchronous and complete, so Data may be reused or freed as soon as this returns.

Channels defaults to 1 and SampleFormat to "Signed16". The buffer must hold a whole number of frames — one frame being Channels samples — and must not be empty; every bound is checked before anything is allocated. A clip may hold at most 512 MiB of decoded samples.

Play

Playback := Audio.Play(Source , Volume, Loop, Pan, StartMilliseconds, Device)

Plays a clip or a file path and returns an Audio.Playback controlling that sound. Source is an Audio.Clip or a path, which is loaded through Load. Volume defaults to 100, Loop to false, Pan to 0, StartMilliseconds to 0 and Device to the current default output.

This is the one-line convenience form. It uses a private output belonging to the calling script, which it never exposes and never shares. Where Audio.Output.Play reports a bounded refusal by returning an empty string, this raises an OSError instead, because a one-line call has nowhere to report one.

A starting point at or past the clip's duration is a ValueError.

There is no process-wide stop. Call Stop on the returned playback, or StopAll on an output you own.

Devices

List := Audio.Devices(Kind)

Returns an Array of every present, usable Audio.Device. Kind is "Output", "Input" or "All" (the default), and any other token is a ValueError. "All" lists outputs before inputs.

A host with no audio at all returns an empty Array rather than raising.

DefaultDevice

Device := Audio.DefaultDevice(Kind)

Returns the current default Audio.Device of one kind, or an empty string when the host has none. Kind is "Output" (the default) or "Input"; a role default is one device, so "All" is a ValueError here.

Sessions

List := Audio.Sessions(PIDOrName, Device)

Returns an Array of every live application audio session, optionally narrowed to one process and one device. A process routinely owns several sessions, so every match is returned rather than the first.

PIDOrName is a process id, or an executable name with or without its .exe suffix. It is not a path: a value containing a slash or backslash is a ValueError. Omitted, it matches every session.

A host with no per-application audio model returns an empty Array.

SetApplicationVolume

Changed := Audio.SetApplicationVolume(PIDOrName, Volume , Device)

Sets one absolute volume on every session of a process and returns how many sessions were changed, which is 0 when nothing matched. Volume is an absolute level from 0 through 100; relative strings such as "+5" are not accepted here.

A session which disappears between enumeration and the write counts as expired rather than failed. If any surviving session refuses the write, this raises an OSError afterwards reporting how many were matched, changed and expired.

SetApplicationMute

Changed := Audio.SetApplicationMute(PIDOrName, Mute , Device)

Sets one absolute mute state on every session of a process and returns how many changed. Mute is a state, not a toggle, because several matched sessions can be in different states.

OnDeviceChange

Hook := Audio.OnDeviceChange(Callback , Kind, Count)

Calls Callback when a device arrives, is removed, is renamed, or becomes the default, and returns the hook controlling the subscription.

The callback is called as Callback(Hook, Kind, Device), where Kind is "Added", "Removed", "Changed" or "DefaultChanged" and Device is the Audio.Device the change concerns. The Kind parameter of OnDeviceChange itself is the filter "Output", "Input" or "All" (the default), and Count defaults to -1 for an unlimited subscription.

Platforms report duplicate notifications, so a change is classified by comparing the previous device snapshot with a fresh one; a notification whose comparison finds nothing fires nothing.

The returned hook carries the shared subscription contract — Stop, Pause, Paused, Status, IsActive, Count and Callback — documented once under Subscription Members. Audio adds nothing to it. The subscription stays registered until Stop(), count exhaustion or script teardown, so dropping the returned hook does not unsubscribe it.

Passing anything but a function is a TypeError; an unknown Kind or an out-of-range Count is a ValueError; and subscribing where IsDeviceChangeSupported is false raises an OSError.

Audio.Device

class Audio.Device extends Object

A snapshot of one audio endpoint, plus the controls that endpoint owns. A device is produced by Audio.Devices and Audio.DefaultDevice, and returned by several other members; calling Audio.Device() throws an Error.

Id is the durable identity. Names repeat and enumeration order changes, so every operation resolves by id and a refresh never adopts a same-named replacement.

MemberDescription
IdThe opaque, platform-assigned identity, compared exactly. Read-only.
NameThe endpoint's display name. Read-only.
Kind"Output" or "Input". A device carries audio in exactly one direction. Read-only.
IsDefaultWhether this device was the default for its kind when the snapshot was taken. Read-only.
IsRunningWhether any application currently holds a live stream on this device, or an empty string when the backend cannot tell. Running is not the same as audible: an open but silent stream still reports true. Read-only.
VolumeThis endpoint's own volume, 0 through 100. Writable.
MuteThis endpoint's own mute state. Writable.
Refresh()Re-reads this exact device. Returns the device itself when it is still present, or an empty string after marking it "Missing".
ToClr()Returns the platform's own device object, for controls this class does not model. Work done through it bypasses this class's caching.

Operating a device whose Status is "Missing" raises an OSError telling the caller to Refresh() first. Reading or writing Volume or Mute on a host without endpoint volume control raises an OSError.

Note: The type of the object ToClr returns is platform-dependent and deliberately unspecified — a Core Audio interface on Windows, something else elsewhere — so a script which uses it is platform-specific by construction. SoundGetInterface is the compatible equivalent, differing in that it resolves an endpoint from a fuzzy name.

Audio.Output

class Audio.Output extends Object
Output := Audio.Output(Device, VoiceLimit, VoicePolicy, LatencyMilliseconds)

An explicit mixer and the one native stream behind it. This is the object a game or any latency-sensitive script owns: it opens once, prepares its clips once, and every later play is a bounded, non-blocking submission which neither decodes nor resamples.

Construction only configures. Nothing native is touched until Open or TryOpen, so an output can be built on a machine with no sound card. Device defaults to the current default output and is followed as that default changes; naming a device pins the output to it. VoiceLimit is 1 through 256 and defaults to 16. VoicePolicy defaults to "Oldest". LatencyMilliseconds is 5 through 500 and defaults to 20; it is a scheduling target, not a promised floor.

A script may hold at most 16 open outputs at once, counting the private one Audio.Play uses. It may likewise hold 8 running recorders and 16 running meters. Each cap exists because dropping a wrapper without closing it leaves its native stream running; going beyond one raises an OSError naming it.

Voice policy

A voice is one sound in flight. When every voice is taken, VoicePolicy decides what a new play does:

TokenBehavior
"Oldest"Ends the longest-running sound and takes its voice. That sound's playback reports "Stolen".
"RoundRobin"Takes voices in rotation.
"Reject"Admits nothing. Play returns an empty string and DroppedPlayCount increases.

Open()Opens the native stream and returns the output, so it chains. Raises an OSError when the device cannot be opened, playback is unsupported, or the open-output cap is reached.
TryOpen()Opens, returning true or false. A missing device or a transient failure is false; an unsupported backend or an exhausted output budget still raises, because those are program errors rather than environment ones.
Prepare(Clip)Converts a clip into the open stream's format ahead of time, so playing it never resamples, and returns the output. Preparing while the output is closed registers the clip, which the next successful open converts along with the others. One output's converted clips may total 512 MiB.
IsPrepared(Clip)Whether that clip is converted for the current stream format. It is false while the output is closed, even for a clip which was prepared.
Play(Clip , Volume, Loop, Pan, StartMilliseconds)Submits one play and returns an Audio.Playback, or an empty string for a bounded refusal: the output is not open, the command queue is full, or a "Reject" policy found no free voice. StopAll()Silences every voice on this output immediately. Idempotent, and valid while closed.
Close()Reversible: retires the native stream but keeps the prepared clips for a later open.
Dispose()Terminal: releases the caches and native state. Later operations raise a ValueError. Dropping the last reference to an open output does the same, so a forgotten output does not hold its stream or its share of the open-output cap until the script exits.

While an output is "Transitioning" after a default change, IsAvailable is false, nothing is prepared, and Play returns an empty string; nothing is played through the stale stream. An output pinned to a specific device which goes away becomes "Unavailable" and waits for that same id to return.

Volume and Mute belong to the open stream: a closed output reports 100 and false, and a value assigned to either while it is closed is discarded. VoicePolicy is held on the output itself, so it survives a Close and applies to the next Open.

Audio.Playback

class Audio.Playback extends Object

One sound in flight. A playback is produced by Audio.Play and Audio.Output.Play; calling Audio.Playback() throws an Error.

Its identity is stable. It never rebinds to a later sound, so a reference kept after the voice was stolen controls nothing rather than controlling a stranger.

Audio.Meter

class Audio.Meter extends Object
Meter := Audio.Meter(Target, IntervalMilliseconds)

An explicit observation of a device's or a session's level. Metering a target whose frames do not pass through the script's own output costs a live native stream on some backends, so a meter is a resource with a lifetime rather than a property which quietly opens one.

Target is an Audio.Device, an Audio.Session, a device selector, or an empty string for the current default output — which makes Audio.Meter() the useful minimal form. IntervalMilliseconds is 20 through 1000 and defaults to 50. Construction snapshots the target and opens nothing.

A meter has no callback: read Peak whenever a value is wanted, for instance from a timer.

MemberDescription
TargetThe device or session being observed, or an empty string when none resolved. Read-only.
Status"Stopped", "Active", "Error" or "Disposed". Read-only.
IntervalMillisecondsThe publication cadence asked for at construction. It is a request, not a guarantee: a backend whose meter is read on demand rather than published has nothing to apply it to. Read-only.
IsSupportedWhether this target can be metered at all. False while no target resolved. Read-only.
PeakThe most recent peak, 0 through 100, or an empty string before any observation completed and while the meter is not active. Read-only.
ErrorAn Error describing why the meter could not open, or an empty string. Read-only.
Start()Opens the native observation and returns the meter. Raises an OSError for an unsupported host, an absent target, or a target which refuses metering. Calling it on an already active meter does nothing.
Stop()Reversible: releases the observation but keeps the target, so Start can be called again.
Dispose()Terminal: stops the meter and refuses a later Start. Dropping the last reference to a running meter does the same.

Audio.Recorder

class Audio.Recorder extends Object
Recorder := Audio.Recorder(Source, Path, Device, SampleRate, Channels, SampleFormat, ChunkMilliseconds, MaximumDurationMilliseconds)

One capture, from a microphone or from what an output device is playing. A recorder is configured first and started second, so an immediate permission or device failure is observable and every option is checked before anything is opened.

Source is "Microphone" (the default) or "SystemOutput". Path is a .wav file to write; left empty, the recording is kept in memory instead. Device is a device selector of the kind that source implies, defaulting to the current default. SampleRate defaults to 48000, Channels to 1, SampleFormat to "Signed16", and ChunkMilliseconds to 100 within 10 through 1000 — the buffer size the capture device is asked for, which a backend may deliver more often than. MaximumDurationMilliseconds is 0 for unbounded, or 1 through 86400000.

A recorder is single-use: construct another for a second recording.

Recording captures whatever the device carries, which can include other people and other applications. Microphone capture requires the script's AudioCapture capability, granted at build time or through RequestCapabilities, and on platforms which ask, the operating system's own microphone permission. A denial raises an OSError naming the privacy setting to change, and no frames are captured.

MemberDescription
Source"Microphone" or "SystemOutput". Read-only.
DeviceThe Audio.Device being captured, or an empty string while the default is used and nothing is open. Read-only.
PathThe resolved destination file, or an empty string for an in-memory recording. Read-only.
Status"Ready", "Opening", "Recording", "Paused", "Finalizing", "Stopped", "DeviceLost", "Error" or "Disposed". Read-only.
DurationMillisecondsHow much audio has been captured. Read-only.
MaximumDurationMillisecondsThe configured bound, or 0 for unbounded. Read-only.
SampleRate, Channels, SampleFormat, ChunkMillisecondsThe configured capture format. SampleRate and Channels report what the device actually negotiated once Start succeeded. Read-only.
PeakThe loudest sample captured so far, 0 through 100, or an empty string before any frame arrived. Read-only.
OverrunCountHow many captured chunks were dropped because the destination could not keep up. Nonzero means the recording has gaps, which is otherwise invisible. Read-only.
ErrorAn Error describing a terminal fault, or an empty string. Read-only.
ResultThe finished Audio.Recording, or an empty string until one exists. Reading it does not stop the recorder. Read-only.
Start()Opens the device and begins capture, returning the recorder. Raises an OSError for an unsupported source, a denied permission or an absent device, leaving the recorder retryable. Starting twice is a ValueError.
Pause()Holds media time without ending the recording. Returns the resulting paused state.
Resume()Resumes and returns the recorder.
Stop()Ends the recording and returns its Audio.Recording, or an empty string when no honest result could be produced. Repeating it returns the same outcome. Stopping a recorder which was never started is a ValueError.
Dispose()Releases the capture and finalizes whatever result exists. Dropping the last reference to a running recorder does the same.

An in-memory recording stops at 10 minutes or 256 MiB, whichever arrives first; a file recording is bounded only by MaximumDurationMilliseconds. The destination's parent directory must already exist — no directory is created. The device is opened before the file is created or truncated, so a failed start leaves no empty file behind; a failure after frames have arrived keeps the partial file and finalizes a valid WAV header where it can.

Platform Support

Playback, clips, device discovery, endpoint volume and mute, and device-change events are part of every backend. What varies is application sessions, metering and capture.

PlatformSessionsMeteringMicrophoneSystem output
WindowsSupportedSupportedSupportedSupported on Windows 10 version 1703 and later
LinuxSupportedSupportedSupportedSupported where the audio server exposes a monitor for the sink
macOSUnsupportedUnsupportedSupportedNot implemented

Each row states what the backend implements. Verification is a separate question, stated per platform below.

Note: WAV decodes everywhere through a managed reader. Compressed containers depend on a codec the host already ships, so what is available varies by machine as well as by platform: Media Foundation on Windows, libsndfile or ffmpeg on Linux, ExtAudioFile on macOS. Ask IsFormatSupported rather than assuming, and Load raises an OSError naming the file when the host cannot decode it. Media Foundation decoding is verified on Windows; the other two are implemented but unverified.

Windows

Implemented over WASAPI and the Core Audio device, session and metering families, and verified on hardware. Output uses a shared-mode event-driven stream; discovery and default-change notifications use MMDevice; Audio.Device.Volume and Mute use the endpoint volume interface; IsRunning reads the device's session states; and ToClr hands out the resolved Core Audio object.

System-output capture uses shared-mode loopback, which delivers frames dependably only on Windows 10 version 1703 and later. On an older build IsSystemAudioCaptureSupported is false rather than opening a stream which would produce audio only while something else happens to be playing.

Linux

Implemented over libpulse, which serves X11 and Wayland sessions alike, and requires a reachable PulseAudio or pipewire-pulse server. Sessions are the server's sink inputs and source outputs, so an application's process name and display name are present only when it published them. Metering opens a peak-detect monitor stream. System-output capture uses the sink's monitor source, which the server exposes for most but not all sinks.

Note: The Linux backend is partly verified. It compiles, and device enumeration, opening an output, polyphonic playback and playback control have been run against a real PulseAudio server. Endpoint volume and mute, sessions, metering and recording have not been exercised there; read those statements as a description of the implementation rather than a tested result.

Note: A PulseAudio capture hands over roughly a tenth of a second of already-buffered audio when it opens, so a recording can be slightly longer than the wall-clock window it was started and stopped in; and a capture opened immediately after another closes on the same source loses a comparable amount while the server re-opens it. Audio.Recorder reports the frames it actually received, so measure from DurationMilliseconds rather than from your own timer, and leave a short gap between back-to-back captures.

macOS

Implemented over Core Audio and AudioQueue for playback, discovery, default-change notification, endpoint volume and mute, and microphone capture.

Session control is unsupported, because macOS exposes no public per-application audio API: Core Audio models devices and streams, not application sessions. Audio.Sessions returns an empty Array, IsSessionControlSupported is false, and SetApplicationVolume and SetApplicationMute raise an OSError. Use Audio.Device.Volume and Mute, or the application's own control.

Metering is unsupported at the endpoint level for a related reason: the Core Audio HAL publishes no peak property for a device, and the one public alternative measures only frames carried by a queue the script itself opened. IsMeteringSupported is false and Audio.Meter.Start raises an OSError. Audio.Output.Peak, Audio.Playback.Peak and Audio.Recorder.Peak measure frames the script already owns and work here.

Capturing what an output device is playing is not implemented on macOS. IsSystemAudioCaptureSupported is false; record from a microphone, or install a loopback device such as BlackHole and select it as the input device.

Note: The macOS backend is unverified. It compiles against the audio contracts, but it has never been run, so no macOS behavior on this page has been observed apart from the two capabilities the platform itself does not offer.

Recording

Note: Recording has been exercised end to end on Linux against a real PulseAudio server, capturing system output to both an in-memory clip and a WAV file, with the written file read back by this class's own decoder. It has not been run against a real microphone on any platform, nor at all on Windows or macOS; on those two, its argument checking, status vocabulary and result contract are covered by tests which run without a sound card, but the captured audio itself is unverified.

Examples

These examples were run on Windows. The macOS backend has never been run and the Linux backend is only partly verified, so none of them is claimed to be cross-platform.

Plays a sound file and waits for it to finish.

#Import "Ks" { Audio }

Sound := Audio.Play(A_WinDir "\Media\notify.wav")
while Sound.IsPlaying
    Sleep 50

Prepares one clip on an output the script owns, then plays it repeatedly. Each press overlaps the previous sound instead of cutting it off, and no press decodes or resamples anything.

#Import "Ks" { Audio }

Click := Audio.Load(A_ScriptDir "\click.wav")
Out := Audio.Output("", 8, "Oldest")
Out.Open()
Out.Prepare(Click)

F3::Out.Play(Click, 70)
F4::Out.StopAll()

Loops background music at a low level, then fades it out and stops it.

#Import "Ks" { Audio }

Music := Audio.Play(A_ScriptDir "\theme.wav", 40, true)

Sleep 5000
Level := Music.Volume
while (Level > 0) {
    Music.Volume := Level := Max(0, Level - 2)
    Sleep 50
}
Music.Stop()

Lists the output devices and their levels, marking the default one.

#Import "Ks" { Audio }

Text := ""
for D in Audio.Devices("Output")
    Text .= D.Name " " Round(D.Volume) (D.IsDefault ? " (default)" : "") "`n"
MsgBox Text

Mutes one application without touching the system volume. Application sessions are unsupported on macOS, so the capability is checked first.

#Import "Ks" { Audio }

Records five seconds from the microphone to a file. This asks for microphone permission on platforms which require it, and captures whatever the microphone hears.

#Import "Ks" { Audio }

Rec := Audio.Recorder("Microphone", A_Desktop "\memo.wav")
Rec.Start()
Sleep 5000
if (Result := Rec.Stop())
    MsgBox "Wrote " Result.Path ", " Round(Result.DurationMilliseconds) " ms"
