#App [Keysharp]

Declares final application facts: identity and metadata, packaged assets, generated host shape, presentation defaults, and fixed integration identifiers.

#App { Key: Value, ... }
#App {
    Name: "MyTool",              ; assembly identity (Assembly.GetName().Name)
    Title: "My Tool",            ; assembly metadata, read back by A_Assembly*
    Company: "Acme Corp",
    Version: "1.2.0",            ; assembly + file version; shown in Explorer properties
    Icon: "assets/app.ico",      ; default window/tray icon AND the compiled executable's icon
    GuiTheme: "Dark",            ; initial A_GuiTheme, applied before runtime windows
    Files: ["assets/*.wav"],     ; embedded for FileInstall
}

Keys

Key names are case-insensitive. Every value must be a compile-time constant: a quoted string, a number, true/false, a . concatenation of constants, or an array of them. An unknown key, a malformed value, or a missing Icon/Files path is a compile-time error.

KeyValueMeaning
NameStringThe compiled assembly's identity — what Assembly.GetName().Name reports and A_AssemblyName reads. Overrides the name otherwise taken from the script's file name.
Title, Description, Configuration, Company, Product, Copyright, TrademarkStringThe matching .NET assembly attribute on compiled output, readable at run time through the matching A_Assembly* variable.
VersionString"major.minor[.build[.revision]]", with 2 to 4 decimal components each from 0 through 65534. Sets both the assembly and the file version, so it also appears in a compiled executable's Explorer properties.
IconStringRelative path to a .ico file. It becomes the script's default icon — the main window's and every GUI's icon, and the tray icon unless #TrayIcon selects another — with no startup flash of the Keysharp icon, and a compiled executable additionally wears it as its win32 icon. At run time, TraySetIcon overrides the tray icon; TraySetIcon("*") restores its embedded tray default, which is this icon unless #TrayIcon selected another.
GuiThemeStringA presentation default: Classic, System or Dark becomes the initial A_GuiTheme. The runtime applies it before creating its windows or dialogs, including an error dialog raised before or during the auto-execute section. It does not affect compile-time errors raised before the script runtime starts.
ConsoleAppBooleanGenerated host shape: builds a compiled executable as a console application, so a shell waits for it and its standard streams are the terminal's. This is the equivalent of AutoHotkey's Ahk2Exe ConsoleApp directive. On Windows this is the executable's PE subsystem, fixed before the process starts; it is ignored when the script is interpreted or compiled to a .cks, and inert on Linux and macOS, where executables have no subsystem.
HookMutexNameStringA fixed integration identifier: the name of the mutex objects used to detect keyboard and mouse hooks in other scripts. The default is Keysharp.
FilesArray of StringsRelative paths of files embedded into the compiled script for FileInstall to extract. Paths are stored as /-separated logical keys; * and ? wildcards are allowed in the file-name segment only. This list is the single authority on what gets embedded; unlike Ahk2Exe, FileInstall calls are not scanned.

Remarks

One or more #App blocks may appear at the top level of the main module. Blocks and their keys are applied in source order, so the last value for a repeated key wins; Files: [] clears an earlier file list. A block in an #Included file counts as the main module's; one inside a function, a class, a #Module or an #Imported module file is an error. Each block uses ordinary object-literal syntax, so it may span multiple lines and carry comments and trailing commas.

Icon and every Files entry must be relative; a rooted path is a compile-time error. Each path resolves against the main script's directory (the program include root), even when the block comes from an included file. This is also the root used by FileInstall in source mode.

The finished manifest is embedded in the compiled assembly as the JSON resource Keysharp.App.json, with any icon beside it. A .cks or executable also embeds each listed file; source-mode execution validates the list but does not snapshot its payloads, so FileInstall copies the live files from disk. The runtime reads the manifest back before the hook thread, tray icon, main window or any runtime dialog exists — in every execution mode — which is what makes these settings bind earlier than any statement could, regardless of where in the file the block sits. An assembly with no such resource has no manifest; if the resource is present but unreadable or malformed, loading the script fails with a hard error. External tools can read a valid resource to inspect a compiled script without executing it.

#App keys independently state final application facts, and all blocks merge into one key/value map; no key acts as a source command or observes intermediate state. Standalone directives select compiler or execution policy, such as front-end diagnostics or launch behavior, or express source-ordered state transitions. #ErrorStdOut changes diagnostic routing when the parser reaches it; #SingleInstance selects launch behavior; and #TrayIcon and #NoTrayIcon transition startup tray state in source order. Startup controls may use the internal manifest resource when the runtime needs their final value before chrome exists, but transport does not determine source syntax and these directives are not #App keys.

Examples

A tool that ships as a dark-themed, single-instance executable with its own icon and a bundled data file.

#SingleInstance Force
#App {
    Name: "Snippets",
    Title: "Snippet Manager",
    Version: "1.0.0",
    Icon: "snippets.ico",
    GuiTheme: "Dark",
    Files: ["snippets-default.json"],
}

if !FileExist(A_AppData "\Snippets\snippets.json")
    FileInstall("snippets-default.json", A_AppData "\Snippets\snippets.json")
