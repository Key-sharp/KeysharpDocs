Documentation Compatibility Target

This documentation branch is based on the AutoHotkey v2.1-alpha.30 reference. The corresponding upstream language changes are preserved in AutoHotkey v2.1 alpha changes.

A compatibility target does not mean that every described feature is implemented identically on every Keysharp platform. Consult the Keysharp capability matrix and test against the current Keysharp release.
