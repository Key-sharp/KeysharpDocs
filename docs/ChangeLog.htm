Recent Changes

This page summarizes the script-visible changes in recent Keysharp releases, so that a script written against an earlier version can be brought up to date. The release page holds the authoritative notes and the downloads for each version.

Note: Keysharp has not reached version 1.0. Behavior can change between releases, including in ways which require edits to existing scripts. Each release below lists its breaking changes first.

0.0.0.16

Released 19 July 2026.

Breaking Changes

  • ImageCapture() was removed. Use the Image class instead.
  • Linux input requires the keysharp-inputd daemon; the SharpHook and X11 fallbacks were removed. See Platform Support.
  • A_ScaledScreenDPI was renamed to A_ScreenScale.
  • A_OSType now returns WINDOWS, OSX or LINUX.
  • A_LineFile in the main file resolves to the main script's full path, as A_ScriptFullPath does.
  • #Import inside a function or class body binds to that scope, and an unknown import throws.
  • Reserved words can no longer be used as variable names.
  • Invalid Gui options now throw instead of being ignored.

New

  • Image captures, loads, creates, draws, transforms, searches and manipulates pixels before saving. It replaces ImageCapture().
  • Overlay is an always-on-top, click-through canvas using the same drawing primitives as Image. It now backs Highlight and ToolTip on Linux and macOS.
  • WinEvent subscribes to window events across platforms: Active, Exist, NotExist, Move, Minimize, Restore and TitleChange.
  • A_ThreadId and Exit with a thread identifier.
  • OnMouseDown, OnMouseUp and OnMouseMove on InputHook.
  • Fully cross-platform monitor functions, plus MonitorGetScale and MonitorFromPoint in the KS module.
  • Gui +ClickThrough and +AutoScroll options.
  • An *Dir scan-direction option for ImageSearch.
  • An OCR library (OCR.ks) with a pluggable engine, and demo scripts including ClipboardHistory, InputHUD, OCRSnip, Shell, WindowGrab and WindowTiler.

Platform

  • Linux: all input channels now go through keysharp-inputd (evdev and uinput), reworked for multi-user handling, per-script permissions, Unicode sending and mouse buttons.
  • Wayland: overlays, clipboard and window manipulation through KWin scripting and Keysharp shell extensions for GNOME (including v48 and later) and Cinnamon.
  • macOS: the hook and sender were revamped on CGEventTap and the key sender is now functional. Binaries are signed, and releases include DMG and PKG packages with SHA256 checksums.

Fixes and Performance

Release-mode stack traces for C# exceptions, OnExit teardown, script exit when the last window closes, thread priority handling and DLL path normalization. Parser fixes for #Include, static variables, dereferences and remap syntax. Regular-expression pattern caching, font caching, cheaper per-call thread setup and faster keyboard-layout queries.

0.0.0.15

Released 22 June 2026. This release made Keysharp cross-platform across Windows, Linux and macOS.

  • macOS support: window management, the keyboard and mouse hook and sender, sound and drive functions, App Switcher integration and native Command-key handling, plus AxSpy, an accessibility inspector.
  • Linux: the inputd input daemon, .deb packaging with automatic .NET 10 installation, Unicode character sending and Keyview syntax highlighting.
  • New parser: a hand-written parser replaced ANTLR4, which is faster and less ambiguous.
  • AutoHotkey v2.1 features: the v2.0 and v2.1 compatibility modes, structs with #StructPack, the #Import directive, PropRef, the !~= operator and ahk_opt.
  • Scheduler: the timer and event scheduler was reworked, fixing timer livelock and timers not firing inside hotkey callbacks.
  • Cross-platform GUI on Eto: DPI scaling, dialog theming, hyperlink labels and A_GuiTheme.
  • The hook and sender were brought current with AutoHotkey 2.0.26.
